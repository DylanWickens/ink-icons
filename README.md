# Ink Icons

A set of chunky 3D icons rendered to look hand-inked, built with Three.js `WebGPURenderer` and TSL.

- **v4 · Ink** – flat cel shading in paper, sand and onyx, with brushy shadow edges, dry-brush grain and a wobbling brush outline.
- **v5 · Vector** – the same brushwork reduced to lines: outer outline, inner contours and the shadow edge, with optional sand shadow fill.

Icons: mail, phone, download, chat check, chat plus, key, settings, checklist, lock plus, lock, grid, hourglass, house, heart.

## Run

```bash
npm install
npm run dev
```

Open the Inspector to tweak light, shading bands, brush and vector-mode settings live.
